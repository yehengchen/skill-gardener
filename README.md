# skill-gardener

![skill-gardener 封面](docs/skill-gardener-cover.png)

skill-gardener 是一个通用型个人 Agent Skill 管理助手。

首次公开日期：**2026-09-07**。

它先通过问答理解任务，再检查现有 Skill 是否已经覆盖需求。只有出现明确能力缺口时，才会寻找新的 Skill，并先放入候选区。候选经过来源核验、同类比较和真实试用后，才进入常用工作库；闲置、重复或停止维护的项目可以进入可恢复归档。

## 它解决什么问题

- 已经装了很多 Skill，但临用时不知道该选哪个。
- 同类 Skill 功能接近，缺少统一比较和试用记录。
- 新工具不断出现，却没有时间逐个筛选。
- 长期闲置或停止维护的 Skill 一直留在工作库里。
- 推荐逐渐锁定在少数熟悉工具，遗漏了更合适的选择。

## 工作方式

```text
了解需求
   ↓
检查现有工作库
   ├─ 已覆盖 → 读取实际入口 → 推荐或执行
   └─ 有缺口 → 核验可信来源 → 候选区 → 比较与试用 → 决定是否启用
                                                   ↓
                                      闲置或不再适用 → 可恢复归档
```

skill-gardener 把个人 Skill 库分为三个区域：

- **工作库（active）**：参与日常推荐和任务路由。
- **候选区（candidate）**：保存待比较、待核验或待试用的 Skill，不默认参与推荐。
- **归档区（archived）**：可恢复出库；归档不会卸载或永久删除 Skill。

## 主要功能

- 根据目标、输入输出、平台、预算、联网条件和偏好筛选 Skill。
- 查询当前可读 Skill 的详细信息。
- 在作者或官方发布日期可核验时回答“最近发布了什么”。
- 发现能力缺口后按需招募新 Skill。
- 通过同类比较和真实试用决定候选去留。
- 收藏常用 Skill，并根据实际成功记录有限调整排序。
- 对闲置、重复或停止维护的项目生成整理建议。
- 提供技能体检、Skill 履历卡、同类擂台和探索位。

## 安装

下载 [通用 ZIP 包](dist/skill-gardener-universal.zip)，或直接复制仓库中的 `skill-gardener` 文件夹到宿主的 Skill 目录。

Codex 的常见本地目录：

```text
$CODEX_HOME/skills/skill-gardener/
```

不同 Agent 宿主的 Skill 发现与启用方式可能不同，请以对应宿主文档为准。安装目录可读不代表相关外部工具或依赖已经可用。

## 使用

可以显式调用：

```text
$skill-gardener
```

第一次可以直接说：

```text
使用 skill-gardener，先问我几个必要问题，再检查现有 Skill 是否能覆盖。
已有合适的就直接推荐；确实缺能力时，再寻找新 Skill 放进候选区。
请不要自动安装，也不要删除任何 Skill。最后告诉我最值得处理的三件事。
```

其他示例：

- “当前可读的 Skill 里，哪些能制作演示文稿？”
- “这个 Skill 为什么还留在库里？”
- “比较这两个同类 Skill，用实际试用结果告诉我该留哪个。”
- “把 90 天没用、也没有收藏的 Skill 放进可恢复归档。”
- “给当前任务一个相关但我还没试过的探索位。”

## 本地数据

个人 Skill 清单、收藏、偏好、评分和试用记录由每位用户在自己的设备上建立。仓库和分发 ZIP 不包含任何用户数据库、个人记录、用户名或本机路径，也没有内置上传与后台同步服务。

默认数据库位置由 Skill 在运行时为当前用户创建，也可以通过 `--library` 指定其他本地路径。

## 运行要求

- Python 3.10+
- 仅使用 Python 标准库
- 外部 Skill 发现依赖宿主提供的联网搜索或浏览能力

## 开发与验证

运行行为测试：

```bash
python skill-gardener/scripts/test_gardener.py
```

当前测试覆盖需求筛选、扫描与问答、候选招募、同类比较、试用晋级、收藏、偏好、技能体检、归档和恢复等核心行为。
